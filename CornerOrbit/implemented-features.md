# Implemented features

- Independent macOS 14+ menu bar app, universal Intel/Apple silicon build.
- Four independent screen corners, each with single/double/triple click and drag into/out actions: 20 bindings.
- Validated portable gesture engine: delayed click disambiguation, drag thresholds, cooldown, modifiers and display separation.
- Explicit Input Monitoring, mouse-only listen tap, no consumed input; disabled by default.
- Native settings, optional hints, display selection, per-corner switches, menu bar pause, data-only starter preset and explicit Run buttons.
- New Chrome tab; searchable Chrome history and optional local recent-websites dropdowns.
- Separate blank Word, Excel, PowerPoint and TextEdit documents using explicitly enabled Automation.
- Installed ChatGPT, Claude, Spotify, Activity Monitor and Finder; WhatsApp Web; custom app/website; Downloads, Applications and System Settings.
- Explicit local read-only Chrome connection and refresh, normal SQLite WAL coordination, bounded queries, cancelable reads and retained dated cache on failure.
- Local atomic settings with validation, malformed-file preservation and explicit reset; recent-link retention is optional, bounded and clearable.
- Native accessibility labels, keyboard selection of websites, Reduce Motion aware popovers and native system appearance.
- Portable and injected native fixtures, actual native preview rendering, universal package metadata, checksum and idle resource check.

Execution status and acceptance limits are recorded in [EVALUATION.md](EVALUATION.md).
