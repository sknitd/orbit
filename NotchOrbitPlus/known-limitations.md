# NotchOrbitPlus known limitations

Source behavior, executed fixtures, connected accounts, physical Mac interaction and trusted distribution are separate evidence. The current source has 45 tools; the preserved download/evidence refers to the previously verified 31-tool build until expanded macOS CI succeeds. [EVALUATION.md](EVALUATION.md) records actual runs, package provenance and remaining acceptance.

## Local models and recording

- Ask Orbit requires eligible macOS 26+ Apple Intelligence hardware/settings and a downloaded Foundation Models model. It has no cloud fallback. File summaries/CSV use only the first 8,000 readable characters per file, not an entire long document. Locked/unreadable PDFs are rejected; screenshot naming depends on real local OCR. Model-generated summaries, tables and names require review and can be wrong. Originals are retained; Undo skips edited/replaced output copies rather than removing someone else's changes.
- Translate requires macOS 15+ and a supported Apple language pair. Explicit Translate may present model-preparation/download UI; initial rendering does not prepare it. Unsupported pairs/models remain unavailable, and there is no remote fallback. Language/hardware acceptance needs the installed Mac.
- Dictation requires available on-device recognition for the chosen language, Speech and Microphone consent. No cloud recognizer or saved audio is used. Shortcut registration, automatic completed-hold Quick Note append and hidden dictation are separate default-off opt-ins. Without hidden-recording opt-in, a hold start must successfully show Dictation before any permission request. A released hold session appends only a real final transcript; cancellation, recognizer failure or the final-result deadline leaves partial text for manual Send. A failed Quick Note save retains text and reports failure. Start-button recordings remain manual. Microphone levels reflect measured audio, not recognition confidence. Real microphones, permissions and global shortcut pairing still require acceptance.
- QR generation/recognition does not establish that encoded links are safe. Scanning a selected screen region requires explicit Screen Recording access; protected/blank content and unrecognized codes are reported without invented results.
- Screenshot/recording capture is silent and bounded to short recordings. Protected-content capture, system audio and long recording are not claimed. Actual permission prompts, Retina/multiple displays, selector interactions and video playback require Mac acceptance.

## Local observation and libraries

- Context service and starter rules start off. Rules use application bundle metadata and actual supplied activity signals, without browser-site/page/content inspection. A first enabled match can select/show only a visible tool; it does not run that tool's actions. Preview does not apply a selection. Sampling while hidden requires its separate opt-in.
- Downloads observes bounded partial-file metadata, not a browser's download API. Totals and ETA are unknown unless the user supplies a valid total; changing files, stalls/resets and uncertain completion invalidate estimates. A matching final file is an observed file, not a browser-confirmed success. Disable never cancels/deletes the browser download. Completion records last only for the session.
- Commands requires Python 3, which the app does not bundle. Explicit helper installation changes only user Application Support, never PATH/system folders. The listener receives cooperative bounded metadata through a private local socket; it cannot inspect every Terminal/Xcode task or infer an unreported exit. Disabling listening does not stop the user's process. `orbit-run` executes the command the CLI user supplies explicitly, while incoming listener messages never execute commands.
- Snippets is bounded to 50 folders/500 snippets/32 KB each/1 MB total; Habits to 100 habits/3,660 dates each/20,000 checkoffs/512 KB. Habit dates use local Gregorian days. These are ordinary local/synced data, not a secrets vault; keep credentials/verification codes out of snippet sync.
- Clipboard private/transient/source markers are respected but cannot detect every secret. Local transforms accept bounded text and known tracking keys; they are not a general privacy scrubber. Search only queries configured enabled/visible local stores; it is not Spotlight, full-filesystem search or remote/account search.
- 2FA Codes needs user-granted Full Disk Access for read-only Messages access. It considers recent incoming plain-text messages with verification context, not rich-body-only messages or every provider format. Codes expire 60 seconds after the message time, are volatile and excluded from persistence/sync. Concealed clipboard copies are skipped by this app's history; other applications may still read the clipboard. Actual Messages accounts/Full Disk Access are not proven by local fixtures, and no account-cache/token inspection is performed.

## Shelf, Inbox and sync

- Shelf collections/rules/entries are bounded. Chosen-folder rules inspect top-level regular files only, skip hidden entries/symlinks and bound file size/enumeration/matches; they are not recursive folder mirroring. Rule definitions may sync, but bookmarks and local enablement do not. Edits/incoming changed definitions require preview/re-enable.
- Expiry only flags candidates. Cleanup requires preview/confirmation and operates on owned copies, preserving originals/references. An explicit entry Remove retains its owned copy for Undo and removes only shelf metadata for references. Undo keeps copies in private retained trash across relaunch; trash is never automatically purged, so retained storage can grow. Undo does not override changed/replaced files.
- Orbit Inbox is an explicit chosen-folder write, not a native iPhone companion, verified iCloud delivery, AirDrop replacement or Handoff integration. Files must be regular and at most 100 MB; UTF-8 notes at most 200 KB. The user opens the same folder in iPhone Files through a suitable provider. A local successful write cannot confirm delivery on another device.
- Sync uses a chosen iCloud Drive/Dropbox/network folder, with readable JSON for anyone who can access it. The expanded build reads schema 1/2 and writes schema 3; older schema-1/2 app packages cannot apply schema 3. All syncing Macs need a compatible expanded build. Local credentials, codes, clipboard, shelf bytes, absolute paths/bookmarks, pick history, Inbox settings and rule enablement are excluded. Folders need local relinking, applications bundle-ID resolution and Shortcuts local availability. Concurrent library edits preserve whole-category variants for explicit resolution instead of collaboratively merging every item. Local fixtures do not prove provider delivery between physical Macs.

## Providers and plugins

- Package Tracker requires an AfterShip key and shipments already registered in the user's AfterShip account; the read-only adapter does not register shipments. It keeps at most 20 local references and limits pagination, so account-wide history is not guaranteed. Optional carrier links open explicitly.
- Travel's authorized Calendar read does not request Calendar consent; connect Calendar separately first. Aviationstack HTTPS/API access depends on the user's plan, and missing optional fields stay unavailable. Calendar numbers/countdowns are not live railway data: no live train-status adapter is implemented. Provider updates are not a guarantee that a departure runs on time.
- Sports supports API-FOOTBALL football teams/matches only, with the user's key and plan limits. There is no default team or synthetic live score. Optional five-minute monitoring can be delayed by network/provider failures. Weather AQI/UV/PM2.5/precipitation are model values; optional threshold notices are not official severe-weather alerts. Real new-provider accounts have not been established by fixtures.
- Requests use fixed approved HTTPS origins and bounded GET responses, rejecting redirects. Keys are local app-specific Keychain entries, not synced. Provider data, missing fields, quotas and errors remain visible; initial view construction does not read keys or contact providers. Existing merchant/stock/GitHub integrations still require their own accounts and permissions.
- Plugin API v1 supports manifest-defined text/lists and explicit shell-builtin actions only, not arbitrary SwiftUI, external executables or unrestricted third-party code. Execution starts off per session. Clipboard/folder access requires reviewed grants; network is denied. Five-second/64 KB bounds apply. The required macOS sandbox runner may be unavailable on a future OS; execution then remains disabled. Bundled samples and local fixtures are not a security audit of every user plugin or future platform.

## macOS interaction and distribution

- MediaRemote is private and can change or be restricted on macOS 15.4+. System playback reports unavailable data; it does not impersonate an entitled process. Music/Spotify are alternatives. LRCLIB requires opt-in plus Lookup, sends available track metadata and may have no match. Track changes cancel requests instead of automatically fetching again.
- Hardware volume/brightness and battery data depend on device/display support. Unsupported keys pass to macOS; missing battery values stay unknown. Input activity is not proof of a particular app's recording. Camera/Focus can be unavailable; Focus exposes only its authorized shared boolean, not a named mode or private Do Not Disturb inference.
- Local tunnel interfaces are indicators, not a VPN security assessment. GitHub API access/rate limits, provider rate dates and physical interface/device changes need acceptance. Legacy focus counts cannot reconstruct historical sessions; completed dated history is preserved rather than invented.
- Focus hiding acts only on explicitly chosen running apps and restores only owned matching process instances. An app that quits/relaunches cannot be treated as the same process; failed restoration is surfaced with Restore Apps Now. No app is launched/quit or previous frontmost application forcibly activated. Dropping files on Quick Launcher invokes the selected app's actual open operation; success does not prove that app understood every format.
- Public window collection behavior provides Spaces placement; private Space IDs/display geometry are not synced. Fullscreen detection uses separately granted Accessibility permission and leaves unknown windows/displays visible. Hover does not take keyboard focus; manual pinning is supported. Interactive VoiceOver, editor focus, Reduce Motion, Spaces, menu fallback, shortcut use and real drops still need Mac acceptance.
- AppIntents run the app in the foreground with bounded regular-file inputs. Memory-backed workflow results publish to Downloads before private input removal. Actual discovery/execution and permissions require an installed Mac.
- CPU/RSS evidence measures finite idle CI intervals, not every Intel/Mac model, prolonged battery impact or 60/120 Hz responsiveness. Expanded fixtures and captures remain pending until recorded in EVALUATION.
- Development packages are ad hoc signed unless Apple Developer credentials are supplied securely to CI. Notarization/stapling and trusted automatic installation require a real signed/notarized same-team release; ad hoc builds provide checksum-verified downloads/manual installation. Hardware Apple Intelligence, merchant/stock credentials, camera, Reminders, Automation and AirDrop acceptance remain separate.
