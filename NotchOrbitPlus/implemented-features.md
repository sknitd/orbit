# NotchOrbitPlus implemented features

The current source registers **45 dashboard tools**, including **14 new tools** beyond the previously verified 31-tool package. It retains its own `com.sknitd.NotchOrbitPlus` identity, macOS 14 minimum and universal arm64/x86_64 build. OrbitDrop and NotchOrbit remain separate applications. This file describes source behavior; [EVALUATION.md](EVALUATION.md) records executed build evidence. The existing download and screenshots retain their previous verified scope until the expanded macOS run succeeds.

## Local assistant, translation, dictation and QR

- Ask Orbit keeps on-device chat/rewrite and adds explicit local-file proposals: text/PDF/Markdown summaries, CSV extraction, suggested filenames and batch screenshot naming. Foundation Models requires eligible macOS 26+ Apple Intelligence; unavailable models are labeled and there is no cloud fallback. Local Vision OCR supplies readable screenshot text.
- File reading is bounded to 16 regular files, 50 MB each and the first 8,000 readable characters per file; PDFs must be readable and unlocked. Generate Preview never renames originals. Users edit proposals and Confirm to create collision-safe copies beside the sources. Source identity/content is rechecked; cancellation rejects stale results. Undo removes only owned unchanged outputs and retains edited/replaced copies. CSV is parsed before preview/export; generated content still requires review.
- Translate uses Apple's weak-linked macOS 15+ Translation framework with explicit source/target selectors, typed text, clipboard load and result copy. Translation/model preparation starts only after Translate; unsupported language pairs and canceled/stale results do not produce claimed success. There is no remote translation fallback.
- Dictation uses available on-device Speech recognition with `requiresOnDeviceRecognition`, explicit Speech/Microphone consent and actual audio-buffer RMS waveform levels. It saves no audio. The configurable default Control-Option-D hold shortcut starts off, as do hidden recording and completed-hold Quick Note append. With append enabled, release sends one actual final transcript through Quick Note's throwing save callback. Manual Start retains explicit Send. Without hidden-recording opt-in, a failed dashboard reveal refuses hold start before permission requests; repeated hidden notifications cancel pending work even before the first visible notification. Cancellation, partial-only recognition and save failures retain text without claiming a successful append.
- QR creates real Core Image PNGs with chosen error correction, local drag/export and collision-safe publication. Explicit Scan Screen Region uses the existing authorized capture/area-selection path and Vision decoding. Scanned content is shown for review; URLs are not opened automatically.

## Context, downloads and commands

- Context Rules and every starter rule default off. Ordered enabled rules match real frontmost/running application bundle IDs or root-supplied meeting/music/Finder-drag activity. A first match can select/show a visible tool; it never launches an application, executes a workflow or inspects browser pages/content. Preview Current Match performs one observation of individually enabled rules without enabling polling or applying a selection. Meeting context is a current authorized Calendar event with a join link; app presence does not prove a call. Undo Last Selection uses the previous tool when available. One-second observation runs only while enabled/visible or after a separate background opt-in.
- Downloads requires Enable and a chosen Downloads/custom folder. A bounded metadata scan observes `.crdownload`, `.part`, `.partial` and `.download` activity, actual stable-file growth and matching new/changed final files. Total/progress/ETA require a user-supplied total and measured regular-file growth; Safari partial directories remain unknown, and paused observation cannot reconstruct missed completions. Stalls/resets invalidate estimates. Reveal checks that the observed path still exists. Pause/Disable controls observation and never cancels or deletes the browser's download.
- Commands requires explicit listener Enable and optional separate hidden listening. Install User Helpers writes byte-verified `orbit-notify`/`orbit-run` only to the app's user Application Support CLI folder, without PATH or system changes. Helpers require Python 3. `orbit-run` executes only the user's explicit argv, preserves stdout/exit code and reports measured duration; cooperative notifier messages are not OS-wide process inspection.
- The command listener uses an owner-private local UNIX datagram socket, bounded versioned JSON and no network endpoint. Incoming messages contain metadata and are never executed. Hiding without background opt-in interrupts tracking instead of inventing a command exit result. Finish requires a matching observed start UUID and label; the Xcode example tracks its wrapped command rather than the entire build automatically.

## Snippets, habits, search and verification codes

- Snippets persists searchable colored text/code folders with explicit copy, drag and paste. The bounded library allows 50 folders, 500 snippets, 32 KB per snippet and 1 MB total. Ordinary-text snippet sync is separately opt-in; secrets and verification codes should remain local.
- Habits records real Gregorian local-day checkoffs, dated streaks and a 49-day heatmap. Today remains available so yesterday's streak is not erased before today ends. Limits are 100 habits, 3,660 dates per habit, 20,000 checkoffs total and 512 KB. Optional sync shares the ordinary habit library.
- Search combines configured local tool, note, task, snippet, clipboard and shelf-metadata sources. It debounces/bounds queries, supports arrow-key result selection and Return activation, respects hidden/disabled sources and revalidates opened files. It does not request integration access, read sign-in caches or perform Spotlight/full-filesystem indexing.
- 2FA Codes reads recent incoming plain-text Messages from `chat.db` only after explicit Enable and user-granted Full Disk Access. Codes remain in memory for 60 seconds from message time; they are not persisted, synced or imported from account caches. Concealed copy markers keep them out of this app's clipboard history. Hidden reading is a separate opt-in; unsupported schemas and rich-body-only messages are labeled unavailable.
- Clipboard adds explicit local JSON formatting/minifying, URL/Base64 encoding/decoding, case changes, outer trimming, line deduplication and known URL-tracking removal. Transform input/output are bounded and remain on this Mac. Invalid input returns an error; copy is explicit. Existing opt-in history and local Vision image OCR remain available.

## File Shelf, rules and Orbit Inbox

- File Shelf adds 20 named collections, metadata-only entry moves, 40 bounded rules and a shared 200-entry limit. Native drop/reveal/drag/share/AirDrop, tags, favorites and Quick Look remain available.
- Capture rules route owned copies and tags. Chosen-folder rules require actual Preview and explicit local Enable, scan top-level regular files of at most 100 MB every 15 seconds and skip hidden files/symlinks. Saved edits or incoming changed definitions switch execution off until reviewed. Folder bookmarks, selected shelf and execution enablement stay local.
- Legacy retention flags candidates for Preview Cleanup and confirmation. Previewed and explicitly enabled expiry rules automatically move expired owned copies to private retained Undo trash, including while hidden. Undo persists across relaunch and disables matching local expiry rules until a fresh preview; IO failures pause retries across relaunch until explicit Retry. Referenced files and original sources are never deleted; retained trash is not automatically purged.
- Orbit Inbox requires a user-chosen folder, Enable and explicit Send for a shelf file or typed note. It publishes unique coordinated atomic copies, accepts bounded regular files/UTF-8 notes and excludes links/folders. The user can open that folder in iPhone Files through their folder provider; success reports only this Mac's local write. No iPhone companion, verified provider delivery or Handoff is claimed.

## Provider tools and weather

- Package Tracker uses read-only AfterShip 2026-07 tracking requests with an explicitly saved user key, up to 20 local references and bounded pagination. Shipments must already be registered in the user's AfterShip account. An optional validated carrier URL opens only explicitly.
- Travel Status reads authorized Calendar departure candidates on explicit Read Authorized Calendar without requesting access itself. An explicitly connected Aviationstack flight adapter returns available actual status fields and calendar-based countdowns. Train live status is unavailable; optional HTTPS operator links open explicitly.
- Sports Scores supports explicit API-FOOTBALL team search/add/refresh and actual live-game status through `fixtures?live=all`. Upcoming fixtures, completed results and match history are unavailable. There is no default team or fabricated match. Optional five-minute background polling can expose fresh actual in-progress games in the compact notch.
- Weather retains explicit chosen-city Open-Meteo forecasts and adds model US AQI, UV, PM2.5 and eight 15-minute precipitation intervals. Optional 15-minute background refresh supplies actual threshold notices, distinct from official severe-weather warnings.
- New provider requests are GET-only, use fixed approved HTTPS origins, reject redirects and bound response bytes/pages. Keychain accounts are app-specific `aftership`, `aviationstack` and `api-sports-football`. No account/key/network read starts from initial view construction.

## Plugins

- Plugins supports a bounded API-v1 `manifest.json` with text/list presentation and explicit shell-button actions; two bundled samples demonstrate the format. Execution defaults off and must be enabled for the session.
- Clipboard read/write, own-plugin-folder write and selected-folder read require separately reviewed grants. Folder access uses local security bookmarks; grants and installation data are not synced.
- The required macOS sandbox runner denies network, external executables/interpreters and undeclared file access. Scripts use shell builtins only, an isolated environment, five-second runtime and 64 KB output limits. Output JSON is validated. Cancellation terminates the task. If the required runner is unavailable, execution fails closed; arbitrary SwiftUI or unrestricted third-party code is not supported.

## Existing media, HUD and capture

- Explicit System playback dynamically loads MediaRemote for real metadata/artwork/supported controls. Missing symbols, restrictions/timeouts/unavailable data return errors; Music/Spotify Automation remains available.
- LRCLIB starts only after opt-in plus Lookup, sends track metadata, bounds/validates responses and cancels on hiding/disconnection/track changes. Imported local LRC works offline.
- Optional volume/brightness interception starts only from Enable with Accessibility consent. Only successfully adjusted supported keys are consumed; unavailable/denied/unsupported controls pass through to macOS.
- ScreenCaptureKit area/window/display PNGs and short silent `.mov` recordings start explicitly with Screen Recording consent. Valid captures become managed shelf copies even with ordinary Auto-save off. Hiding/cancellation stops capture and removes partial output. Saved image/video workflows run explicitly, preserve originals, validate smaller video output and roll back failures; image/video stages cannot mix.
- Color Picker samples only on Pick, copies multiple code formats, retains local history and persists optional synced sRGB palettes. Devices/Status read available battery/input/camera/authorized Focus information without inventing missing values. Network uses local traffic deltas/tunnel indicators without an external probe.
- Converter's explicit-refresh currencies use actual provider dates. World Clock validates chosen-zone/DST conversions and reads already-authorized Calendar meetings. GitHub Actions is token-based explicit read-only Connect/Refresh. Focus Stats charts real completed sessions, preserving unreadable history and refusing to invent legacy dates.

## Interaction, focus and sync

- Hover expansion does not activate the app or take keyboard focus; manual pinning keeps tools open. Quick Launcher application pins accept actual regular-file drops and open them with the selected app. An optional menu-bar left click opens tools on notchless displays; right click retains the status menu.
- Timers offers explicit chosen-app preview/Enable for focus hiding. Pause/end/cancel/Disable restores only process instances this feature hid, checked by PID and launch date. Recovery ownership is persisted; Restore Apps Now retries actual failures. No apps are quit or launched.
- All 45 tools participate in visibility/order/onboarding. Native observers defer/coalesce callbacks outside SwiftUI graph updates and stop on retained-window hide/teardown. Hidden tools stop sampling/capture except their explicit background opt-ins. Context selectors and capture overlays do not bypass explicit-hidden cancellation.
- Editable compact priorities include processing, HUD, dictation, codes, meetings, travel, focus, commands, downloads, music, packages, sports, weather, devices and status. Per-display widths/enabled choices, Spaces placement, opt-in Accessibility fullscreen hiding, System/light/dark theme, accent and default-off success sound remain implemented.
- Shared-folder sync defaults off. Schema 3 reads schemas 1/2 and adds independently versioned snippet/habit/shelf-definition libraries to notes/tasks/launcher/workflows/palettes/portable settings. Credentials, codes, clipboard, file bytes/paths/bookmarks, Inbox configuration and rule enablement stay local. Changed rule definitions require fresh local enablement. Concurrent whole-category variants retain explicit resolution and private backups; failed multi-store apply rolls back or retains private recovery and blocks further sync.
- Five foreground AppIntents expose Start Focus, Add File to Shelf, Run Workflow, Toggle Dashboard and Capture Screenshot with bounded files and durable workflow outputs. Native keyboard/VoiceOver labels/Reduce Motion remain implemented. Smoke launch records measured idle CPU/RSS with raw intervals/budgets; executing new native tests, captures and hardware acceptance is separate from these source claims.

No telemetry or cloud AI is added. Provider access, permissions, helpers and optional background activity require explicit user controls. See [known-limitations.md](known-limitations.md) for platform, account and distribution limits.
